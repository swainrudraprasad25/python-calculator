# Python Calculator

A simple command-line calculator built with Python. Perform basic arithmetic operations and chain calculations together.

## Features
- Addition, Subtraction, Multiplication, Division
- Continue calculating with the previous result
- Start a new calculation anytime

## How to Play
1. Run `python main.py`
2. Enter the first number
3. Pick an operation: `+`, `-`, `*`, `/`
4. Enter the next number
5. See the result
6. Type `y` to continue calculating with the result, or `n` to start over

## Run
```bash
python main.py
```

## Files
- `main.py` – calculator logic
- `art.py` – welcome banner art

## Example
```
What is the first number?: 10
+
-
*
/
Pick an operation: +
What is the next number?: 5
10.0 + 5.0 = 15.0
Type 'y' to continue calculating with 15.0, or type 'n' to start a new calculation: n
```
